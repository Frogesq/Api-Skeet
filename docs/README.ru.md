# Skeet · Lua API для CS2

Скрипты Skeet используют Lua 5.5.0 и API версии 3. Они могут подписываться на игровые события, получать снимки сущностей, запрашивать обработку движения, создавать элементы меню и рисовать интерфейс. Каждый скрипт загружается из собственного файла.

## Начало работы

1. [Загрузка и структура скрипта](QUICKSTART.ru.md) — расположение файлов, редактор, перезагрузка и данные.
2. [Среда выполнения](RUNTIME.ru.md) — глобальные имена, доступные библиотеки, обработка ошибок и лимиты.
3. [Жизненный цикл и события](EVENTS.ru.md) — порядок вызовов, доступные операции и поля обработчиков.

## Как читать контракт

Точка в имени разделяет модуль и функцию. Аргументы перечислены в порядке вызова. `?` у аргумента обозначает необязательное значение, а `nil` среди результатов означает, что данные могут отсутствовать. События определяют момент, когда разрешены отрисовка и командные запросы. Проверяйте фазу и время жизни данных в руководстве модуля.

Для редактора доступны [декларации Lua](api.lua) и [декларации FFI](ffi.lua). Если функция вернула ошибку или скрипт отключился, откройте [диагностику](TROUBLESHOOTING.ru.md).
