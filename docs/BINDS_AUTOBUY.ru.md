# Бинды и автозакупка

## Бинд на настройку меню

Найдите точные `category` и `name` через `settings.list()`. Поле `bindable=true`
означает, что к настройке можно добавить штатный индикатор `[клавиша]`.

Первый вызов добавляет бинд к кнопке превью. Второй задаёт Rotation=90 при
удержании F; после отпускания возвращается исходное значение. Клавиша и режим
редактируются рядом с самой функцией: левый клик назначает клавишу, правый
выбирает режим. Escape снимает клавишу. Режимы: 0 Toggle, 1 On hotkey,
2 Off hotkey, 3 Always on.

Для чекбокса активное значение — true. Для чисел, списков, цвета, текста и
массивов передавайте `value` соответствующего типа. Индексы штатных списков
обычно начинаются с 0; это не индексы `ui.create("combo")`, которые начинаются
с 1. Значение должно подходить диапазону и смыслу конкретной настройки.
Цвет с биндом получает отдельную подписанную строку, чтобы индикатор не
перекрывал колорпикер.

Регистрация сохраняется вместе с обычным конфигом. Выгрузка Lua её не удаляет.
Загрузка конфига без этой регистрации удаляет добавленный бинд. При повторном
вызове `add_bind` существующий бинд сохраняется; `replace=true` явно заменяет
его. Для удаления используйте `settings.remove_bind(category,name)` и сохраните
конфиг. `settings.bind(category,name,key,mode)` меняет клавишу/режим существующего
штатного или добавленного бинда. Сохранение конфига выполняется обычной кнопкой
Save; вызовы Lua не перезаписывают файл автоматически.

Бинды управляют значениями настроек. Они не добавляют вызовы к кнопкам Load,
Save, Reset и другим действиям без зарегистрированного поля. Скинченджер,
внутренние custom-поля, приватные menu.cfg-параметры и принудительно включённая
штатная ватермарка исключены. `settings.set/override` по-прежнему не записывают
боевые настройки; разрешение на бинды отдельно от `writable`.
Не назначайте одновременно бинд и постоянный Lua override одному полю:
они записывают одно значение и будут конкурировать.

## Команды покупки

Покупка использует общий интерфейс игровой консоли. Доступность предмета и время покупки определяются правилами сервера. Название события и переданные поля описаны в [Событиях](EVENTS.ru.md), правила передачи команды — в [справочнике консоли](reference/console.md).
