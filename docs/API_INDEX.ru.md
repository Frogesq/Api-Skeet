# Lua API 3

Выберите модуль, затем функцию. В карточке указаны аргументы в порядке вызова, допустимые значения и результаты. Знак `?` обозначает необязательный аргумент или возможный `nil`, `[]` — массив, `...` — переменное число значений. Несколько результатов возвращаются по порядку. [Структуры данных](TYPES.ru.md).
