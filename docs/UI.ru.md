# Контролы, окна и оформление меню

Во всех текстовых полях Skeet ручной ввод принимает английские буквы, цифры,
пробелы и обычные знаки ASCII, кроме обратной кавычки. Это относится и к контролам `ui.create("text", ...)`.
Поиск в оболочке NL принимает также китайские и португальские символы и находит настройки по переведённым названиям.
Значения, заданные скриптом или загруженные из файлов, автоматически не очищаются.
Поле активируется нажатием мыши; символы добавляются в конец, Backspace удаляет
последний символ, Ctrl+Backspace очищает поле, Escape завершает ввод. Ctrl+A выделяет
всю строку: ввод заменяет выделенное, Backspace или Delete удаляет его. Подчёркивание
обозначает конец строки; активный текст выделен цветом меню. Буфер обмена и
перемещение курсора в этих полях не используются. Лимит строки зависит от поля;
контракт `ui.create("text", ...)` сохраняет прежний предел 4096 байт.
В редакторе Lua ввод и вставка также ограничены ASCII, с сохранением переносов
строк и табуляции; существующий исходник при открытии не переписывается.
Ctrl+A в области кода выделяет весь исходник. Окно редактора перемещается за верхнюю
полосу; поле имени нового скрипта занимает ширину окна с боковыми отступами.

Штатные `Safety Mode` и `Limiter` удалены из Skeet. Их старые значения в
конфигурациях игнорируются и не включают ограничения при загрузке конфига.

## Контролы конфигурации

Создавайте `ui.create` один раз на верхнем уровне. Возвращаемый id принадлежит текущему скрипту. Внутри него id должен быть уникальным, длиной 1–80 байт; label — до 160 байт. Лимит — 128 контролов.

| kind | default | Дополнительные аргументы |
|---|---|---|
| `checkbox` | boolean | Необязательная таблица `{key=VK, mode=0..3}` |
| `button` | false | `ui.get(id)` возвращает true один раз после нажатия |
| `slider` | Число внутри диапазона | minimum, maximum; minimum < maximum |
| `combo` | Индекс от 1 | Таблица из 1–512 строк, каждая до 160 байт |
| `color` | Четыре целых RGBA 0–255 | Нет |
| `text` | Строка до 4096 байт | Нет |

`ui.get(id)` возвращает значение, `ui.set(id, value)` проверяет и меняет его. У checkbox с биндом get учитывает действующий бинд. Тип и диапазон должны соответствовать созданному контролу. Для combo используется нумерация с **1**, не с 0.

Кнопки опрашивайте в `paint`: `if ui.get(button) then ... end`. Нажатие
потребляется первым чтением; `ui.set` для кнопок не используется. Нажатия
не сохраняются в конфиг и не выполняют Lua непосредственно из отрисовки меню.

`ui.bind(id)` читает бинд checkbox; `ui.bind(id, key, mode)` назначает его. Режимы: toggle `0`, hold_on `1`, hold_off `2`, always_on `3`. Клавиша `0` снимает назначение; always_on работает и без клавиши. Значения ui.create и бинды сохраняются вместе с конфигурацией Skeet. Сохраните конфиг через меню, чтобы перенести их между запусками. Обычная перезагрузка Lua в текущем процессе также сохраняет значения контролов. Storage использует отдельный файл и не заменяет сохранение конфигурации.

## Окна скрипта

Параметр `key` задаёт клавишу независимого окна. `key=0` привязывает видимость к меню Skeet. По умолчанию для key=0 окно открыто, для отдельной клавиши — закрыто. Follow-окно не станет видимым поверх закрытого меню только из-за `ui.set_window_open(id, true)`.

Размеры: ширина 180–1600, высота 120–1600 пикселей; defaults 320×360, позиция 120×120. Лимит — 8 окон на скрипт. Окно можно двигать и менять его размер.

`ui.attach_window(control, nil)` возвращает контрол на штатную страницу скрипта. `ui.window_bind(id)` читает key/open/follows_menu; второй аргумент меняет клавишу. `ui.set_window_open(id, open)` задаёт состояние. `ui.get_window(id)` возвращает текущий прямоугольник и параметры.

## Мышь и положение главного меню

В `paint` доступны:

- `ui.is_menu_opened()` — открыто ли меню Skeet.
- `ui.get_menu_rect()` — `{x,y,w,h}` в экранных пикселях.
- `ui.mouse_state()` — `{x,y,down,clicked}`.

Все paint-обработчики получают один и тот же click. Проверяйте попадание в свой прямоугольник и завершайте перетаскивание при отпускании или закрытии меню. Для отдельного окна с контролами используйте `ui.create_window` и `ui.attach_window`.

## Цвета, прозрачность и шрифты

Получите поддерживаемые имена через `ui.style_colors("menu")`. `ui.set_style_color("menu", name, color)` устанавливает override; `color=nil` снимает свой. Не угадывайте ключи цвета по подписи пункта меню.

`ui.set_blur_opacity(surface, opacity)` принимает `sidebar`, `header`, `body`, `surface`, `card`, `control` и число 0–1. nil снимает override. `ui.reset_theme()` освобождает оформление, установленное этим скриптом.

`ui.set_menu_skin(options)` задаёт оболочку штатного меню: размеры боковой панели
и заголовка, фон, палитру и оформление контролов. Сами настройки и бинды остаются
штатными. При выгрузке возвращается прежняя геометрия окна. Параметры, совместимость
с отдельными окнами и параметры ресурсов описаны в [оформлении меню](MENU_SKIN.ru.md).

`ui.set_menu_font("font.ttf", 11)` выбирает файл непосредственно из `%LOCALAPPDATA%\skeet`; поддерживаются TTF/OTF/TTC/OTC, размер 8–24. Возвращаются success и возможная ошибка. nil вместо файла снимает свою настройку. `ui.get_menu_font()` возвращает effective language, source (`default`, `menu`, `language`), filename и size. Успешное назначение готовит настройку; создание GPU-шрифта происходит в следующем кадре меню.

Это шрифт штатного меню. Для текста Lua и игровых ESP-подписей применяются отдельные методы [render](RENDER.ru.md).

## Перевод меню

Словарь сопоставляет точный английский видимый текст с UTF-8 переводом. Получите допустимые ключи через `ui.get_translation_keys()`. Они не содержат служебный суффикс `##`. Отсутствующая строка отображается по-английски. Ваш собственный текст Lua, исходник и лог не переводятся автоматически.

В Misc → Language доступны English (`en`), 简体中文 (`zh-CN`, упрощённый китайский) и Português (Brasil) (`pt-BR`, бразильский португальский). Lua для выбора этих языков не нужен; выбранный ID сохраняется в конфигурации. Переводятся штатные разделы, настройки, списки, подсказки, редактор и окна подтверждения. Названия предметов из каталога CS2 используют язык игры; пользовательские имена файлов/моделей, текст Lua-интерфейса, исходники и сообщения скриптов остаются исходными.

id пользовательского языка: ASCII-буквы, цифры, `-`, `_`, 1–48 байт; name: 1–96 байт. Встроенные `en`, `zh-CN` и `pt-BR` зарезервированы. `ui.get_languages()` перечисляет сначала эти три языка, затем пользовательские по ID; `ui.get_language()` возвращает действующий id; `ui.translate(text, id)` переводит отдельную строку, по умолчанию в текущий язык. Готовые словари: [中文](menu-localization.zh-CN.json) и [Português (Brasil)](menu-localization.pt-BR.json).

`ui.set_language_font(id, filename, size)` назначает шрифт только своему языку. Он имеет приоритет над общим menu-font override. nil снимает шрифт языка. `ui.unregister_language(id)` снимает свой словарь. При выгрузке владельца словарь удаляется, а недоступный выбранный язык отображается с fallback на English.

## Контролы в существующих блоках меню

`ui.get_menu_groups()` возвращает пары `tab` / `group` с точными английскими
именами доступных блоков. `ui.attach_menu(control, tab, group)` добавляет
собственный контрол скрипта в конец существующего блока. Перевод меню на имена
API не влияет.

Неизвестная вкладка или блок вызывает ошибку, не меняя прежнюю привязку.
Новые рамки/блоки этим API создать нельзя. Контрол использует обычную прокрутку,
шрифты и ширину элементов блока, перемещается вместе с ним. Несколько скриптов
могут добавлять свои контролы; выгрузка одного не удаляет контролы остальных.
Значения и бинды сохраняются в обычном конфиге. Место размещения задаёт скрипт.
Контрол остаётся доступен на его странице в CONFIG.

`ui.attach_menu(control, nil)` снимает размещение. Вызовы `attach_menu`,
`attach_tab` и `attach_window` заменяют предыдущую привязку этого контрола.
Добавление в `LUA` / `A` или `LUA` / `B` показывает общую скрытую вкладку;
после удаления последнего владельца она скрывается.

## Общая скрытая вкладка Lua

`ui.create_tab(id, title, options)` регистрирует разделы текущего скрипта и
показывает вкладку `Lua` после CONFIG. Одновременно могут работать несколько
таких скриптов. Каждый владеет своими id и контролами; один скрипт может
зарегистрировать одну вкладку с 16 группами. Внутри отображаются штатные блоки
`A` слева и `B` справа, с прокруткой и обычными контролами Skeet. Блоки можно
перемещать за заголовок и растягивать за нижний правый угол, как остальные
блоки меню. Reset Menu возвращает их исходное расположение. Появление вкладки
Lua не увеличивает окно меню.

`ui.create_tab_group(tab,id,title,column,layout)` добавляет группу в колонку
1 или 2. Группы нескольких владельцев размещаются последовательно внутри A/B.
Без групп контролы попадают в A. Создавайте группы до привязки контролов.
`ui.attach_tab(control,tab,group)` требует группу, если они созданы;
`ui.attach_tab(control,nil)` снимает привязку. Настройки остаются доступны
на странице выбранного скрипта в CONFIG.

`ui.remove_tab(id)`, выгрузка или ошибка освобождают только разделы владельца.
Когда владельцев больше нет, вкладка скрывается; если она была выбрана, меню
возвращается в CONFIG. Боковое обозначение — текст `Lua`, как на проверенном
пути донора. `ui.set_tab_style(id,options)` сохраняет старые параметры как
метаданные; title используется для группы без секций. Старые icon, texture,
text_colors и layout top/bottom/span не меняют общую вкладку. Нельзя перекрасить
или переименовать вкладку всех скриптов из одного скрипта.

## Самостоятельное меню со страницами

У `ui.create_window` параметр `style="menu"` включает рамку, фон, верхнюю линию
и элементы главного меню. Минимальный и стандартный размер — 660×560. Цвета
следуют MISC / Settings; изменения видны сразу. Обычный `style="panel"`
остаётся стандартным вариантом для маленького окна.

`ui.create_window_page(window,id,title,icon)` добавляет боковую страницу;
icon — текстовый символ UTF-8, до 16 байт. До 8 страниц на окно.
`ui.create_window_group(window,page,id,title,column,layout)` добавляет блок:
колонка 1/2, необязательные `{top=0,bottom=1}` в долях высоты, минимальная
высота 0.12. Пересечения запрещены. До 16 групп на окно; id группы уникален
в пределах окна. Сначала создайте страницы и группы, затем прикрепляйте контролы
третьим аргументом `ui.attach_window`. Внутри блока есть штатная прокрутка;
геометрия блоков задаётся Lua и меняется пропорционально размеру окна.

`ui.get_menu_colors()` возвращает `{accent,top_line,custom_top_line}` из текущих
настроек меню. Это чтение: функция не сохраняет и не меняет menu.cfg.
Временные цветовые патчи Lua сюда не входят.
